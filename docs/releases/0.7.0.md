# 0.7.0

直接使用 Harness 实现 ACP v1 和实验性 v2，不再转发官方 ACP。两种协议共用同一套会话执行代码；模型选择、权限确认、MCP、计划进度、会话标题和工具分类继续可用。

## 新增与修复

- v2 在消息进入会话后返回消息 ID，执行进度和结束原因通过独立状态通知发送。
- v2 支持忙碌时排队，以及恢复会话时按需回放历史消息和工具记录；消息 ID 在重启后保持一致。
- 取消排队消息不会中断 Harness 正在执行的任务。关闭会话会等待执行退出，先通知最终空闲状态，再返回关闭响应。
- 模型选择在本轮固定，修改只影响后续轮次；MCP 配置替换等待当前任务结束，失败时恢复原配置。
- 删除原有 ACP relay。Harness 固定为 `0.2.1-rc.4`，ACP TypeScript SDK 固定为 `2.1.0`。

## 升级

```bash
npm install -g @dumbo-ai/dsh-acp@0.7.0
dsh-acp --version
```

从 0.6.0 升级后重启客户端即可。启动命令、环境变量和 `--patch` 用法不变；现有客户端继续协商 v1，支持实验性 v2 的客户端可选择 v2，无需新增参数。安装本包会自动安装 Harness，不需要另装 `dsh`。

v2 仍是实验性协议，不代表已实现全部可选扩展。当前支持标准 stdio/HTTP MCP，尚不支持 MCP-over-ACP；消息和思考也不逐 token 输出。完整能力边界见 [README](../../README.md)。
