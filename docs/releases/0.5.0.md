# 0.5.0

本版本升级到 DeepSeek Harness `0.2.1-rc.4`，要求 Node.js `>=24.9.0`。

## 更新内容

- 同步 Harness 和 Cordis 依赖，移除上游已撤下的 `dsh-subagent-in-process-driver` 直接依赖。默认启动继续使用官方 ACP profile。
- 修复兼容适配器的工具结果转换：从新版 tool-role message 读取调用 ID、失败状态和完整内容，支持空结果。
- README 和客户端配置示例统一推荐全局安装后直接启动 `dsh-acp`，默认不需要 `cordis.yml`。

## 验证范围

- `pnpm check`：类型检查、lint、构建及 50 项测试通过。
- npm tarball 独立安装：命令入口、API 导出、Harness 依赖版本一致性检查及 2 项 ACP 端到端测试通过。
- 真实 ACP 子进程：初始化、模型列表、模型和推理强度切换、MCP 工具、权限确认、用量通知、会话列出与重启恢复、取消和失败后的下一轮对话。
- 兼容适配器：工具成功、失败和空结果；取消、失败、队列和清理等会话生命周期回归。
- DeepSeek 实际 API：正常回复、关闭进程后恢复会话，并通过下一轮回复确认历史仍然可用。验证环境为 macOS arm64、Node.js 24.13.0。

默认模式的完整 ACP 支持范围见 [README](../../README.md#默认模式的-acp-支持范围)。自定义完整 Cordis 配置需要使用与 Harness `0.2.1-rc.4` 对应的插件名称和字段。本次验证不覆盖旧版本历史会话格式迁移。

## 升级

```bash
npm install -g @dumbo-ai/dsh-acp@0.5.0
dsh-acp --version
```

显示 `0.5.0` 后重启客户端。已有配置使用 `dsh-acp` 或其绝对路径且安装位置不变时，无需修改启动配置。
