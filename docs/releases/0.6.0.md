# 0.6.0

默认使用 Harness 0.2.1-rc.4 的官方 ACP，并增加计划进度、会话标题和工具分类。历史会话列表读取 Harness 已保存的标题，保留官方的筛选、排序和分页；没有可用标题缓存时保留无标题条目。移除旧适配器；会话执行、取消、结束判断和持久化只由官方实现负责。

## 升级

- 无参数启动的用户升级后重启客户端即可。
- 删除旧 `--config` 参数，必要的自定义设置改用 `--patch`。工作目录中的 `cordis.yml` 不再自动加载。
- 自定义 ACP 模型补丁的目标从 `id: acp` 改为 `id: dsh-acp`。
- 旧的 server/runtime API 及 `./runtime` 导出已移除。程序化接入改用根入口或 `./plugin` 导出的 Cordis 插件。
