# DeepSeek Harness 0.1.6-alpha.1 upgrade

## Goal

Upgrade `@dumbo-ai/dsh-acp` to DeepSeek Harness `0.1.6-alpha.1` while preserving the package's official-profile default and legacy adapter API.

## Design

The zero-argument CLI continues to delegate to the official Harness `acp` profile. This lets the upstream profile supply MCP SDK v2 negotiation, paginated tool discovery, shared MCP resources, Messages API routing, and the revised asynchronous Agent creation lifecycle without duplicating those implementations here.

The package pins every directly consumed Harness package and the official profile's root peer capabilities to the same release. Explicit peer pins prevent package-manager resolution from mixing the alpha profile with older prerelease capability implementations. The removed `@deepseek-ai/dsh-code-runtime` dependency is not replaced because this repository does not import it; the official `@deepseek-ai/dsh` package owns the new PTC runtime dependency graph.

The legacy complete-Cordis adapter continues to await `AgentFactory.createAgent()`. The new upstream `agent/created` lifecycle therefore completes before a runtime session is returned, with no adapter-side lifecycle bridge required.

## Verification

- Validate manifest version alignment and the absence of the retired runtime package.
- Run type checking, linting, build, and all unit and protocol tests.
- Exercise official-profile initialization and session creation through the built CLI.
- Pack and install the tarball in a clean temporary project, then run the installed executable.
