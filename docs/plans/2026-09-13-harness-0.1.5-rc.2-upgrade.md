# DeepSeek Harness 0.1.5-rc.2 upgrade

## Goal

Upgrade the adapter from DeepSeek Harness `0.1.1-rc.2` to `0.1.5-rc.2` after the upstream removal of `@deepseek-ai/dsh-agent-spine-demo`.

## Decision

The zero-config CLI delegates to the official DeepSeek Harness `acp` profile. That profile owns the maintained base composition and now implements model controls, image admission, MCP mounts, persistent session listing and resume, permission requests, and quiescent turn settlement. The package keeps its existing programmatic adapter exports and its complete-Cordis `--config` mode for embedded callers.

Profile customization uses repeatable `--patch` files. A current-directory `cordis.yml` or explicit `--config` continues to select the legacy complete-config boot path; these modes are mutually exclusive with `--patch`.

The adapter package moves to `0.3.0` because its zero-config runtime changes from the removed demo spine and local protocol implementation to the upstream ACP application.

## Verification

- Type-check and test the retained programmatic adapter against the new Harness APIs.
- Start the official ACP profile with an isolated `DSH_HOME` and negotiate ACP initialization.
- Start the legacy complete-config fixture and complete a prompt lifecycle.
- Pack and install the npm tarball in a clean directory, then verify the executable entry point.
